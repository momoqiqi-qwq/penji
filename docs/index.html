数据链路

一条链路，只留一种数据来源

传感器读数、农事记录、投入品台账在同一个批次上汇合，二维码是这个批次的出口。每一环都能回答「这条数据是谁采的、从哪来的」。

  1. 1
    SENSE

    传感器

    MQTT 直连、云开发 watch、演示兜底三选一，四个参数为一帧。

  2. 2
    STORE

    readings 集合

    以服务器时间为准，900 ms 内的重复帧丢弃，日聚合可重复执行。

  3. 3
    DERIVE

    环境评价与 OPI

    与农事记录、投入品台账在批次上汇合，算出有机生产评价。

  4. 4
    ARCHIVE

    批次档案与二维码

    一个批次一张码，档案随记录一起增长。

  5. 5
    LOOK UP

    扫码的两端

    消费者看生长过程，采购商核验并录入检测结果。

三种身份

同一份数据，三种看法

身份决定你看到什么、能改什么。权限只在一处判定：auth.canEdit、canUpload、canReview、canInspect。

农户

土地的主人
  • 地块与批次建档，一季一档
  • 农事记录与投入品台账，随手一记
  • 本地规则库的农技诊断，离线可用
  • 环境实况与曲线，来源如实标注

演示账号：张老汉 F-001、王秀英 F-002、李建国 F-003、赵桂花 F-004

消费者

扫码的人
  • 扫一张码，进这一批菜的档案
  • 看 OPI、检测报告、农事与环境曲线
  • 评价与反馈，直接影响农户信用
  • 不用注册成农户，扫码即看

演示账号：任意，不绑定农户与采购商

采购商

收菜的人
  • 主推地块按成熟倒计时排序
  • 看中就预订购，锁住这一茬
  • 批次核验：同一张码，另一套视角
  • 录入食品检测，不合格一票否决

演示账号：演示采购商

核心能力

六件事，做扎实

不做大而全。传感器、档案、信用、评价、诊断、核验，每一件都要能被追问到「这个数哪来的」。

【实时直连真实数据】【云端采集真实数据】【演示模拟数据】

空气温湿度、光照、土壤湿度。三种来源各有一个标签，不混用，不省略。

架构

只有一个入库口

页面从不直接读写存储，也不引用演示数据。utils/store.js 是唯一的数据访问层。换成云开发时只改这一个文件，页面一行不动。

页面17 个页面只调用 store.js，越权时给出明白的提示再退回
数据层utils/store.js唯一的读写入口，每次写入都会重算信用分
实现mock.js 与 wx.cloud接口不变，实现可替换：本地演示或云开发

设计系统

四条硬规则

全部 token 在 app.wxss 顶部。规则的目的是让 17 个页面看起来出自一个人之手。

  1. 01

    绿色只有四级

    ink、green、lime、green-mist。需要第五种绿，说明设计出了问题。

  2. 02

    字号只有六级

    20、22、24、26、32、40 rpx。页面里不会出现 27rpx 这种数字。

  3. 03

    阴影永远两层

    近处一层实，远处一层散。单层阴影显得廉价。

  4. 04

    圆角只用四档

    r-sm、r-md、r-lg、r-xl，不随手写像素值。

唯一例外是角色色：农户绿、消费者蓝、采购商金。它们只用来表示「这是谁」，不进入业务语义。

已知边界

现在还不是成品

溯源产品最不能做的事，是把演示数据说成真实采集。所以没做完的部分也列在这里。

P0数据层仍是本地 mock

多设备看到的是各自的本地数据。要上线，需按 store.js 的接口逐个换成云开发实现。

P0照片不落云存储

选完图只存了临时路径，重进小程序即失效。接入 wx.cloud.uploadFile 后写回 fileID。

P1设备密钥是字面量

ingest 里的演示密钥只用于本地跑通，生产环境必须走环境变量 PENGJI_DEVICE_KEYS。

P2没有自动化测试

目前只有静态自检。信用分、OPI、诊断引擎适合补纯函数单测。

云开发未就绪时，登录会降级为「本机身份 · 未连云端」，首页如实标出，不假装核验过微信身份。

上手

三分钟跑起来

不需要云环境，也不需要后台账号。演示数据会在第一次打开时自动写入。

  1. 1

    克隆仓库

    用微信开发者工具打开项目根目录。

  2. 2

    跑一遍自检

    npm run check 检查 JSON、页面四件套、tabBar 一致性、事件处理器、主包体积等 10 项。

  3. 3

    先选身份

    农户、消费者、采购商看到的首页完全不同。选错也没关系，顶部随时可以切换。

  4. 4

    重置演示数据

    调用 utils/store.resetAll()，或清掉本地缓存（存储键 pengji_mock_v6）。
